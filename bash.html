Bash Apprentice

Turn commands into scripts.

A Bash script is a short text file containing commands. Add variables, decisions, loops and functions, and a list of instructions becomes a small program.

The shape of a script

A script usually begins with a shebang, a special first line that tells the system which interpreter should read the file. For Bash, the common form is #!/usr/bin/env bash. After that, each line is a command the shell can run.

#!/usr/bin/env bash

name="Tux"

echo "Hello, $name!"

Hello, Tux!

Before a script can be run directly, it needs execute permission. A file can also be read explicitly by Bash, but learning the permission step helps explain why scripts behave like small programs.

Variables store values

A variable is a named place for a value. In Bash you assign it with name=value, with no spaces around the equals sign. You read it by writing a dollar sign before the name, such as $name.

Quoting matters. Double quotes allow variable expansion while keeping spaces together, as in "Hello, $name". Single quotes print the text literally.

echo prints, read listens

echo writes text to the terminal. read pauses and stores what the user types in a variable. Together they make a simple conversation possible.

read -p "Your name: " learner

echo "Welcome, $learner!"

Welcome, Aisha!

Conditions choose a path

An if statement runs one block when a test is true and another block when it is false. In Bash the block ends with fi.

if [ "$answer" = "yes" ]; then

echo "Let us continue."

else

echo "Maybe next time."

fi

The spaces inside the square brackets are part of the syntax. Quote variables so a blank or spaced value does not break the test.

Loops repeat work

A for loop walks through a list and runs the same block once for each item. This is useful when you have several files or commands to review.

for tool in pwd ls cd; do

echo "Review: $tool"

done

Functions package a useful block

A function gives a block of commands a name. You can then call it repeatedly instead of copying the same lines. Values passed to a function are available as $1, $2 and so on.

greet() {

echo "Welcome, $1!"

}

greet "Tux"

Welcome, Tux!

Put it together

Real scripts grow by combining these small pieces. Start with one clear task, print what is happening and test often. Readability matters more than cleverness when someone else has to maintain your script.

  • Choose a descriptive script name.
  • Keep each block focused on one job.
  • Quote variables that may contain spaces.
  • Test with harmless values before using important files.
