Safety first

How the simulator stays safe

  • Commands are matched against a fixed allow-list.
  • Files and folders exist only in a virtual tree.
  • Dry runs reset to a predictable starting state.
  • Errors explain what went wrong.

The simulator never calls a real shell, never uses eval(), and never sends data anywhere.
