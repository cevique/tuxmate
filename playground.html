Design rules

How practice will work

  • Commands are matched against a fixed allow-list.
  • Files and folders exist only in a virtual tree.
  • Exercises have predictable starting states.
  • Errors explain what went wrong.

The simulator will never call a real shell, use eval() or send data anywhere.

Start with these building blocks

Review the lessons first, then test your understanding with the matching quest.

  • pwdPrint the current location in the virtual filesystem.
  • lsList the files and directories at the current location.
  • cdMove between virtual directories using safe paths.
  • catRead a text file from the virtual tree.
  • mkdir / touchCreate a practice directory or empty file.
