Linux Foundations

Software arrives in packages.

A package manager keeps track of what is installed, where it came from and which other pieces it needs. It is one of the main reasons Linux systems stay tidy.

Instead of hunting for files on random websites, a Linux distribution keeps a catalogue of tested software and a tool that installs it consistently.

What is a package?

A package is an archive containing program files plus metadata: its name, version, description and any other packages it needs. On Debian, Ubuntu and Linux Mint, packages usually end in .deb.

The package manager records what was installed, so it can update or remove the software later without leaving you to guess which files belonged to it.

Repository

Where packages live

A repository is a store of packages and index files, often served over the internet. Your system keeps a list of enabled repositories in its configuration.

Dependency

What a program needs

A dependency is another piece of software required for a program to work. Package managers follow these relationships automatically.

APT in plain language

APT is the package management system used by Debian and its descendants, including Ubuntu and Linux Mint. It reads repository indexes, resolves dependencies and hands installation work to lower-level tools.

These examples are for reading, not for running here. TuxMate never executes package commands.

$ sudo apt update

Refresh the list of available package versions

$ sudo apt install sl

Install a package and any missing dependencies

$ apt search terminal

Search package descriptions for a word

Update is not the same as upgrade

apt update refreshes the catalogue of what is available. It does not change your installed programs. apt upgrade installs newer versions of packages you already have.

Confusing the two is a common early mistake. If nothing seems available after a release, refresh the catalogue first.

Why dependencies matter

Imagine installing an image editor that needs a shared library to read PNG files. The editor's package declares that dependency. APT checks whether the library is present and installs it if needed.

This is safer than manually downloading separate files, because the package manager tracks versions and can remove software cleanly later. Other distributions use different tools, such as pacman on Arch Linux, but the underlying ideas are similar.

Be careful with administrator rights: commands prefixed with sudo can change the whole system. Read the package name and the action preview before confirming.
