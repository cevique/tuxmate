Terminal Explorer

The prompt is a map.

The terminal is a text window; the shell is the program inside it that understands your commands. Learn both, and the filesystem stops feeling like a maze.

You do not need to memorise hundreds of commands. Start with a mental picture of where you are, what is nearby and how commands are spelled.

Shell versus terminal

A terminal is the window that displays text and accepts keyboard input. A shell is the program running inside that window. The shell reads what you type, finds the matching program and passes along any arguments.

Bash, short for Bourne Again SHell, is the default shell on many Linux distributions. When you see a prompt such as tux@tuxmate:~$, the shell is ready for a command.

The filesystem is one tree

Unlike systems with separate drive letters, Linux presents files as a single tree. The tree starts at /, called root. Everything else hangs from it, including other drives once they are mounted.

  • /home holds personal directories for users.
  • /etc holds system configuration files.
  • /usr holds many installed programs and shared data.
  • /var holds changing data such as logs.
  • /tmp holds temporary files that are often cleared on restart.

Absolute path

Starts at root

/home/tux/notes.txt names the file from the very top of the tree. It works no matter where you currently are.

Relative path

Starts here

notes.txt means the file in the current directory. .. means the parent directory, and . means the current one.

Your first navigation commands

Try reading these examples rather than typing them into a real machine. The playground will offer a safe place to experiment when the simulator is ready.

$ pwd

/home/tux

$ ls

notes.txt projects

$ cd projects

$ pwd

/home/tux/projects

Directories and files

A directory is a container for other files and directories. A file stores data such as text, an image or a program. Commands let you inspect and change both.

  • pwdPrint the current directory so you always know where you are.
  • lsList the names of files and directories in a location.
  • cdChange directory, using either an absolute or a relative path.
  • mkdirCreate a new directory with the name you provide.
  • touchCreate an empty file or update its modification time.
  • catPrint the contents of a text file to the terminal.
  • cp / mvCopy or move files. Moving is also how you rename a file.
  • rmRemove files. Pause and check the path before using this one.
  • manOpen the manual page for another command.

Commands are programs, not magic words. If a command is missing or behaves differently, the shell is telling you something useful about your system.
