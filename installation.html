Linux Foundations

Install with a plan.

A Linux installation is straightforward when you know what the installer will do. Prepare carefully, read each screen and never accept a disk action you do not understand.

These steps describe the shape of a typical desktop installation. Always follow the official guide for the distribution you choose, because wording and screens differ.

Check the hardware first

Most current computers can run a beginner-friendly Linux desktop. A common baseline for a smooth experience is a 2 GHz dual-core processor, 4 GB of RAM, about 25 GB of free storage and a USB port. Older machines may still work with a lighter desktop, and some distributions need more space.

Treat those numbers as a starting point, not a promise. Check the distribution's own requirements before you download an installer image.

Try a virtual machine first

A virtual machine, or VM, runs Linux inside a window on your existing system. The installer writes to a virtual disk file instead of repartitioning your real drive, so it is a useful way to rehearse the screens before committing to a full installation.

VMs share hardware with the host, so graphics and performance may be slower. They are a rehearsal space, not a replacement for a backup when you later install on real hardware.

Prepare without surprises

  1. Choose the distribution. Revisit Choosing a distribution if you are still deciding.
  2. Back up your files. Copy documents, photos and project work to another drive or cloud storage. An installer can change disks permanently.
  3. Download from the official site. Use the project's own download page so the image has not been altered.
  4. Create a bootable USB drive. Follow the official instructions and understand that the drive will be erased when it is written.
  5. Note your network details. Knowing your Wi-Fi name and password makes the first boot much easier.
  6. Decide about other operating systems. Replacing a whole disk is simpler than dual booting, but it removes what was there. Read every confirmation carefully.
Safety note: TuxMate does not install Linux and never runs commands on your computer. This page is a learning guide only. If a step in an installer is unclear, stop and read the distribution's documentation.

A beginner-oriented walkthrough

The exact order varies, but most graphical installers follow this pattern:

  1. Boot from the USB drive. Use your computer's boot menu to start from USB instead of the existing system.
  2. Try the live session. Many installers let you test the desktop before changing the disk. Check keyboard, trackpad, display and Wi-Fi here.
  3. Start the installer. Choose your language, keyboard layout and time zone.
  4. Choose the installation type. “Erase disk” is only appropriate when you intend to replace that entire disk. For dual boot, use the installer's guided option and review the proposed partitions before continuing.
  5. Create your account. Set a name, computer name and strong password. Decide whether automatic login is appropriate for your setting.
  6. Review the summary. Confirm the target disk, partition changes and user details. This is the last calm moment to catch a mistake.
  7. Install and restart. Let the installer finish, remove the USB when prompted and reboot into the new system.
  8. Apply updates. Sign in and use the distribution's update tool. The next lesson explains what is happening in Package managers.

After the first boot

Install any firmware or driver updates offered by the system, restore your backed-up files and explore the desktop settings. Keep a note of what you changed; it makes a second installation much easier.

If something feels strange, remember that Linux separates the kernel, tools and desktop. Knowing which layer an issue belongs to helps you search for the right answer.
