About TuxMate

Learn Linux by playing.

TuxMate is a small semester project that turns Linux commands and Bash scripting into a friendly pixel-art adventure.

Course

Introduction to ICT

This website was built as a lab project for the Introduction to ICT course.

Team

Battler, Parri & Mani

The project is maintained by three teammates working with HTML, CSS and vanilla JavaScript.

Privacy

No accounts, no tracking

Progress stays local. TuxMate does not collect personal information or send it anywhere.

Contact

Send a message to the team

Questions or feedback? This form hands your message to FormSubmit, which delivers it to a developer inbox. TuxMate does not store or send anything itself.

Placeholder address in use: linus@kernel.org. Replace it in the form action with the developer inbox before publishing.

Before you send

One message, no account

FormSubmit needs your email so a developer can reply. TuxMate has no backend and keeps no copy of the message.

The first submission activates the address with FormSubmit. Follow the confirmation email they send to the inbox.
