Linux Foundations

Linux is more than a penguin.

To use Linux well, it helps to know what is underneath: an operating system, a kernel, a collection of tools and a community that shares the source code.

Linux is often described as one thing, but it is really a set of layers that work together. Each layer has a clear job.

An operating system manages the machine

An operating system, or OS, sits between your programs and your hardware. When a browser saves a download, the OS finds space on the disk, remembers the file name and decides which program may read it. When several apps run at once, the OS shares processor time and memory between them.

Familiar desktop operating systems include Windows, macOS and Linux distributions. They all solve the same basic problem: giving programs a safe, organised way to use the computer.

Kernel space

The privileged core

The kernel runs with full access to the CPU, memory and devices. Normal programs cannot simply reach into that space; they ask the kernel through defined requests.

User space

Everything you launch

Your editor, browser and shell all live in user space. They are separate programs that rely on the kernel for files, processes and device access.

The kernel is the core

Linux, strictly speaking, is a kernel: the central program that starts the system and mediates access to hardware. It handles processes, memory, filesystems and network connections. The original Linux kernel project began in 1991 and grew through contributions from programmers around the world.

A kernel alone is not a complete desktop. It needs utilities, libraries, configuration and applications before a person can log in and work.

GNU tools make the system usable

The GNU project created many of the programs that people use every day on Linux systems: a shell, a compiler, text tools and small utilities such as ls and cp. A distribution combines the Linux kernel with these GNU components and other software.

This is why you will sometimes see the name GNU/Linux. It recognises that both the kernel and the wider set of tools matter.

A distribution packages the whole experience

A Linux distribution, or distro, is a complete package: kernel, system libraries, desktop environment, package manager and default applications. Ubuntu, Linux Mint, Debian, Fedora and Arch Linux are all distributions built around the Linux kernel.

Because distributions choose their own defaults, they feel different even though the underlying ideas are shared. Compare them in Choosing a distribution.

Open source is about access to the source

Linux is free and open-source software. Its source code is published, and its licence allows people to study, modify and share it. That openness lets students read real code, lets companies adapt it and lets communities fix problems together.

“Open source” does not only mean “no price”. The key point is that the source is available and the licence protects the freedom to use and improve it.
